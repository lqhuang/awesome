# Lean

- [gh:leanprover/lean4](https://github.com/leanprover/lean4): Lean 4 programming language and theorem prover <https://lean-lang.org>
- [gh:lean-dojo/LeanDojo](https://github.com/lean-dojo/LeanDojo): Tool for data extraction and interacting with Lean programmatically. <https://leandojo.org>
- [gh:ImperialCollegeLondon/group-theory-game](https://github.com/ImperialCollegeLondon/group-theory-game): Building group theory from scratch in Lean
- [gh:leanprover/cslib](https://github.com/leanprover/cslib): The Lean Computer Science Library (CSLib) <https://www.cslib.io/>
- [gh:leanprover-community/mathlib4](https://github.com/leanprover-community/mathlib4): The math library of Lean 4 <https://leanprover-community.github.io/mathlib4_docs>
- [gh:leanprover-community/physlib](https://github.com/leanprover-community/physlib): A project to digitalise results from physics into Lean. <https://physlib.io>
- [gh:leanprover-community/batteries](https://github.com/leanprover-community/batteries): The "batteries included" extended library for the Lean programming language and theorem prover
- [gh:leanprover/hex](https://github.com/leanprover/hex): Verified computational algebra in Lean 4: aggregator for the released hex libraries <https://kim-em.github.io/hex-dev/>
- [gh:leanprover/fp-lean](https://github.com/leanprover/fp-lean): Functional Programming in Lean
- [gh:leanprover/verso](https://github.com/leanprover/verso): Lean documentation authoring tool <https://verso.lean-lang.org/>
  - [gh:leanprover/verso-web-components](https://github.com/leanprover/verso-web-components): A collection of reusable components from the Lean website designed build related sites with the same look and feel.
